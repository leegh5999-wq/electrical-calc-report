## 3. 분전반 시트의 동적 참조 패턴 (중요)

각 분전반 시트(`LS-1F-A` 등)는 정적 참조 외에 **`INDIRECT` 기반 동적 참조**를 사용:

```excel
=IF($A10="","",INDIRECT("'"&$B10&"'!$AT$4"))         # B10에 "LP-1F-A" 같은 시트명 저장
=IF($A10="","",INDEX(INDIRECT("'"&$B10&"'!1:65536"),$C10,COLUMN()))
=VLOOKUP($A10,조명기구,5,0)                          # 조명기구 카탈로그
=INDEX(조명기구!$H$4:$H$152,MATCH(A10,조명기구!$C$4:$C$172,0))
```

**의미**:
- B열에 부모 분전반 시트명을 문자열로 적어두면 그 시트의 특정 셀을 가져온다 → **분전반 간 부모-자식 관계** (예: LS-1F-A는 LP-1F-A의 합계를 인용).
- 정적 의존성 그래프(40 edges)는 실제 의존성을 과소집계 → 웹앱에선 분전반 사이에 명시적 "parent panel" 필드를 둬야 함.

## 4. 분전반 시트 인벤토리 (Ch.5)

모두 동일한 82행 × 66열 템플릿. 차이는 회로 수(formulas 100~1,600)와 부하 종류(L=조명, S=콘센트, P=동력, T=특수부하, EV=전기차).

| 그룹 | 시트 | 용도 |
|------|------|------|

| LS (light secondary) | LS-1F-A, LS-2F-A, LS-3F-A, LS-1F-B, LS-2F-B, LS-3F-B | LP에 종속되는 보조 분전반 |

| L- (room) | L-1F-급식, L-2F-교수학습, L-2F-체육, L-3F-교사연구, L-3F-과학, L-3F-컴퓨터, L-3F-기술가정 | 실별 분전반 |
| S- (서비스/관리) | S-B1F-전기실, S-1F-주방+L-1F-주방, S-1F-관리, S-1F-행정, S-2F-교무, S-3F-서버 | |

## 6. 추천 빌드 순서 (의미 기반 위상정렬)

1. **Phase 0 — Reference Data Import** (계산기 아님, JSON 자료화)
   - CB, CABLE DATA, 장비일람, DF(수용률), 조명기구, 설계조건
2. **Phase 1 — 변압기 용량** (Ch.1, 가장 단순, 표준 검증)
3. **Phase 2 — 발전기 용량** (Ch.2, 독립적; 부하집계 + KDS + PG법 + 수용률 + 접지)
4. **Phase 3 — 분전반 템플릿 + 40개 데이터셋** (Ch.5, 부모-자식 관계 모델링)
5. **Phase 4 — 전압강하** (Ch.3, 분전반 결과 소비; 가장 큰 시트)
6. **Phase 5 — MCC(간선)** (Ch.4)
7. **Phase 6 — 트레이** (Ch.6, 케이블 트레이 사이즈/포설)
8. **Phase 7 — 통합 + 인쇄 리포트 + GitHub Pages 배포**

## 7. 데이터 모델 핵심 아이디어

```
설계조건 (1개)                    ┐
  └─ 변압기계산 (1개) ─┐         │
  └─ 발전기계산 (1개) ─┤         │
  분전반 (N개, 부모-자식)        │  ← localStorage 키: ecr.project.<schoolId>
    ├─ 회로 (M개)               │
    └─ 부모분전반 ref           │
  MCC (3개)                     │
  트레이 (2개)                   │
  └─ 전압강하 (분전반에서 자동) ─┘
```

JSON 스키마는 Phase 0 끝에서 확정하고, 이후 단계는 그 스키마를 점진적으로 채워나간다.
